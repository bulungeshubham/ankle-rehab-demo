# Ankle rehabilitation dashboard demonstration

[Open the live demonstration](https://ankle-rehab-prototype.streamlit.app/)

This demonstration contains simulated IMU values only. It does not connect to hardware, drive a motor, or include patient records. The main project is maintained separately in the private ankle-rehab repository.

The hosted interface includes monitoring, calibration guidance and demonstration CSV exports. USB and OpenCV acquisition remain local to the laptop. Deployment uses streamlit_app.py and Python 3.11.
